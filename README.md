ORBIT — IAT 2027 Research Desk

ORBIT is my personal study dashboard designed to help me prepare for the IAT and NEST 2027 examinations while building a strong foundation for a future in scientific research.

Goals

- Organize daily and weekly study tasks.
- Track chapter-wise syllabus completion.
- Manage revisions and unfinished tasks.
- Record mock test performance.
- Monitor study progress and time spent.

Technologies

- HTML
- CSS
- JavaScript

Purpose

This is a personal productivity project built to support consistent studying, independent learning, and my long-term goal of pursuing physics research.

Project status: In development.
